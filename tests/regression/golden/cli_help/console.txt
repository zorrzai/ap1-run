usage: ap1-run [-h] [--config CONFIG] [--fixture-dir FIXTURE_DIR]
               [--output-dir OUTPUT_DIR] [--ap1-text AP1_TEXT]
               [--rescore TRANSCRIPT]

Run the AP-1 instrument smoke test against a live endpoint. The endpoint, the
model and every other setting come from the config; only the API key comes
from the environment (AP1_SMOKE_API_KEY).

options:
  -h, --help            show this help message and exit
  --config CONFIG       the run configuration (default: example/config.json)
  --fixture-dir FIXTURE_DIR
                        the directory holding fixture.json, questions.json and
                        ground_truth_example.py (default: example/)
  --output-dir OUTPUT_DIR
                        where the transcript, report and summary are written;
                        files of the same name there are replaced (default:
                        output/)
  --ap1-text AP1_TEXT   the AP-1 text to seal; its hash must match the
                        config's ap1_text_hash (default: the text of the
                        config's ap1_version under reference/)
  --rescore TRANSCRIPT  instead of running, score a run's transcript again (no
                        endpoint, no key), with the run's --config and
                        --fixture-dir, into another --output-dir
